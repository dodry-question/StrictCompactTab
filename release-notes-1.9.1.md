Version 1.9.1 delivers important visual and alignment corrections to the Settings sidebar interface. In the inline shortcut edit form, all buttons and the custom icon upload button are now perfectly center-aligned and share a matching 36px height. Interactive select dropdowns and input fields in the Light Theme have been redesigned with a bright, crisp white background and clear borders. Input text and placeholder elements inside the Light Theme settings panel have been adjusted to high-contrast dark colors for maximum accessibility. Finally, the inline edit form's background has been updated to a soft light-grey overlay in Light Mode, preventing dark dark-theme container colors from bleeding through transparent inputs.
