Version 1.9.2 introduces an important correction to the shortcut icon management logic. The "Reset" button inside the inline shortcut editor is now dynamically shown only if the edited shortcut actually has a custom icon assigned. This is handled by appending a dynamic class hook onto the editor container through JavaScript when an icon is uploaded or deleted. The CSS stylesheet is configured to hide the reset button by default, cleanly overriding any pre-existing button display rules. This update ensures that standard shortcuts remain visually uncluttered and only reveal the custom icon reset controls when relevant.
